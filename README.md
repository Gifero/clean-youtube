# Clean YouTube

Extensión para Firefox / Zen que:

- Oculta los **YouTube Shorts** (barra lateral, inicio, búsqueda, canales).
- Redirige los enlaces `/shorts/ID` al reproductor normal.
- Oculta los vídeos **exclusivos para miembros**.
- Permite activar/desactivar cada opción desde el icono de la barra.

## Privacidad
No recopila ni envía ningún dato. Solo guarda tus dos ajustes (activado/desactivado) en el almacenamiento local del navegador. Solo se ejecuta en youtube.com.

## Instalación (desarrollo)
`about:debugging#/runtime/this-firefox` → *Cargar complemento temporal…* → selecciona `manifest.json`.
